# Tic Tac Toe Game (Python)

## Description
This is a simple command-line Tic Tac Toe game developed using Python. It allows two players to play against each other in a turn-based format.

## Features
- Two-player gameplay
- Interactive command-line interface
- Input validation for correct moves
- Win and draw detection logic

##  Tech Stack
- Python 3

## How to Run
1. Make sure Python is installed (Python 3.x)
2. Clone the repository:
   git clone https://github.com/abhinav-s-kumar-07/pythongameproject_tictactoe.git
3. Navigate into the folder:
   cd pythongameproject_tictactoe
4. Run the game:
   python pythonproject.py

##  Game Logic
- The game is played on a 3x3 grid
- Players take turns marking X and O
- First player to align 3 marks (row, column, diagonal) wins
- If all cells are filled with no winner → Draw
